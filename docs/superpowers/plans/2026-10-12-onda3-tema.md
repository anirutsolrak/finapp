# Onda 3 — Tema (claro pastel + escuro neutro) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Execução nativa, em modo ponytail. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar o visual preto-azulado por um tema claro em tons pastéis (padrão) e um escuro em cinzas neutros, ambos legíveis.

**Architecture:** As telas usam ~500 classes Tailwind fixas (`bg-gray-900`, `text-white`, `text-emerald-400`...). Em vez de reescrever todas, a paleta é remapeada em um ponto: `tailwind.config.js` aponta a escala `gray`, `white` e os tons de texto dos acentos para variáveis CSS; `src/index.css` define as variáveis para claro (`:root`) e escuro (`:root[data-theme="dark"]`). Nenhum JSX muda de cor, exceto texto sobre botão de acento.

**Tech Stack:** Tailwind 3 (cores `rgb(var(--x) / <alpha-value>)`), CSS variables, Vitest.

**Spec:** pedido do usuário — "cansei dessa cor escura, ruim pra ler e pouco atrativa; tons pastéis ou tons mais escuros neutros pro modo escuro".

## Global Constraints

- Sem dependência nova.
- Texto sobre superfície: contraste WCAG ≥ 4.5:1 nos dois temas (verificado por teste).
- Tema inicial segue o sistema operacional; a escolha manual fica em Configurações e persiste em `localStorage` (`finapp:theme`).

## Decisões de paleta

| Papel | Classe existente | Claro | Escuro |
|-------|------------------|-------|--------|
| Fundo da página | `bg-gray-950` | areia `#F4F1EA` | carvão `#18181B` |
| Cartão / modal | `bg-gray-900` | `#FFFDF9` | `#212125` |
| Campo, borda, faixa | `gray-800` / `gray-700` | bege `#ECE7DD` / `#DDD6C9` | `#2C2C31` / `#3F3F46` |
| Texto (título → dica) | `text-white` … `text-gray-600` | `#1B1916` … `#6F685E` | `#FAFAFA` … `#8E8E98` |
| Acento | `emerald-500/600` | menta `#5DBE9A` / `#48AA86` | `#56BE98` / `#46AA86` |
| Texto de acento | `text-*-200/300/400` | tom 700 da cor | tom 300/400 da cor |
| Texto sobre acento | novo `text-onaccent` | verde-escuro `#10241C` | igual |

Os fundos tingidos (`bg-emerald-500/20`, `bg-red-500/10`...) viram pastéis sozinhos sobre o fundo claro.
